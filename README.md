# Specyfikacje datapacku

| Dokument | Zakres |
|---|---|
| [Modele statyczne](STATIC_MODEL_FORMAT.md) | Budynki, infrastruktura, roślinność i wyposażenie świata. Zawiera także wspólne reguły glTF, materiałów, świateł, metadanych przestrzennych i sterowania. |
| [Modele dynamiczne](DYNAMIC_MODEL_FORMAT.md) | Pojazdy i ich wyposażenie: animacje, podwozie, drzwi, sprzęgi, oświetlenie, kabiny, mechanizmy i IK. Rozszerza reguły wspólne profilu statycznego. |

Oba dokumenty mają status projektu specyfikacji 0.3.0. Własne pola `extras` są propozycją kontraktu dla eksporterów i silnika. Odwołania do glTF i rozszerzeń Khronos wskazują standardową reprezentację danych.
